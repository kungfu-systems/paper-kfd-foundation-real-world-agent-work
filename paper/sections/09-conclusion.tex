\section{Conclusion}

Agent participation makes previously implicit boundaries load-bearing. The
problem is not only that agents may act incorrectly. Humans and agents can lose
the ability to reconstruct which facts governed the work, why a claim should
be trusted, and how responsibility crosses systems and time.

This paper presented an ordered foundation: facts must not drift; trust must
start from facts; cooperation must start from trusted value. It then derived
procedures for declared perspective, coupled human--agent primitive discovery,
and an experimental autonomous loop grounded in causal experience.

The comparative cases suggest a common candidate pattern. Xinfa Atlas mediates
project reality and shared understanding. Kungfu Episode mediates action and
real-world result. Buildchain Release Passport mediates reviewed source/build
activity and released truth. They are not important merely because they record
information. They attempt to turn coordination once held in human memory into
stable boundary objects that software can manage.

Project Cut shows how such objects can compose without becoming one universal
authority: Git carries material publication, Atlas carries epistemic closure,
Episode carries causal transition, and Release Passport carries promotion
responsibility. The resulting loop can expose reality pressure to later human
and agent reasoning while preserving facts, gaps, and independent assessment.

The next requirement is not a stronger slogan. It is harder evidence:
adversarial deletion, cold-start recovery, fault injection, held-out and
prospective evaluation, independent adoption, and explicit rejection of false
candidates. If the objects survive those tests, boundary-primitive discovery
can become an engineering discipline for expanding human--agent capability in
reality. If they do not, the same foundation requires the claims to be narrowed
or abandoned.
