\section{Related Work}
\label{sec:related}

\subsection{Boundary objects and distributed cognition}

Star and Griesemer introduced boundary objects as artifacts that are adaptable
to local needs while maintaining a common identity across social worlds
\cite{star1989boundary}. Xinfa Atlas is closest to that tradition: human and
agent projections differ while binding the same semantic root. The present
work uses \emph{boundary primitive} more narrowly for a candidate promoted into
a systems object with declared authority, lifecycle, operations, and
falsifiers. It also treats pressure at the contact surface as a discovery
diagnostic, not as a definition of all primitives.

Distributed cognition studies how cognition is organized across people,
artifacts, and environments \cite{hutchins1995cognition}. Engelbart's
augmentation program similarly framed computing as increasing collective
human capability rather than merely automating tasks
\cite{engelbart1962augmenting}. This paper extends those positions to systems
where agents are reasoning participants and the shared artifacts must carry
fact, trust, and responsibility boundaries.

\subsection{Situated action and coordination}

Suchman shows that plans and situated practice cannot be collapsed into one
static instruction model \cite{suchman1987plans}. Winograd and Flores emphasize
commitment and coordination in work \cite{winograd1986understanding}. The KFD
foundation shares the view that action is situated and cooperation is not
reducible to command execution. Its specific contribution is an engineering
chain from non-drifting facts through purpose-bound trust to collaboration and
reviewable records.

\subsection{Events, traces, and provenance}

Event sourcing reconstructs state from recorded events
\cite{fowler2005eventsourcing}; distributed tracing preserves causal
relationships among runtime operations \cite{opentelemetry}; and Lamport's
ordering model distinguishes causality from a universal physical clock
\cite{lamport1978time}. Episode and KFD-4 build on these concerns but add a
first-class unit of work, declared observer, responsibility, proof, and
decision boundary. A trace span is useful evidence inside an Episode without
becoming the Episode's complete authority.

Software supply-chain systems make artifact origin and build process
inspectable. SLSA defines provenance expectations \cite{slsa}, while in-toto
models authorized supply-chain steps and evidence \cite{intoto2019}. Release
Passport is compatible with these mechanisms. Its additional focus is the
post-build responsibility record: reviewed promotion, channel movement,
compatibility impact, artifact/package set, transaction recovery, and the
first machine-readable entrypoint an agent should inspect.

\subsection{What remains distinct}

Existing work provides important components: shared boundary artifacts,
situated coordination, causal ordering, tracing, and provenance. This paper's
distinct claim is their ordered composition into a foundation for real-world
agent work and a falsifiable procedure for discovering when implicit
coordination should become a new load-bearing object.
