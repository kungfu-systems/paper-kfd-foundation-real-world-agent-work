\section{Evidence Paths}
\label{sec:evidence}

This draft is a foundation paper. Its claims should become stronger through
concrete evidence. We identify three evidence paths.

\subsection{The KFD package}

The KFD repository and npm package are a self-proof case. The package exposes
decision texts, a registry, standards metadata, schemas, site bundle data, and
checks. It gives both humans and agents a stable path for reading the same
foundation. It also publishes KFD-owned schemas for contract-world witnesses,
trust taxonomy, trust claims, trust assessments, collaboration interfaces, and
observer perspectives.

This package can demonstrate that the model is not only prose. KFD-1 is
expressed as contract-world metadata. KFD-2 is expressed as trust taxonomy and
assessment schemas. KFD-3 is expressed as collaboration interface and witness
schemas. The package becomes an example of the model bearing itself.

\subsection{Buildchain}

Buildchain is the release and provenance evidence path. It can test whether
non-drifting contract worlds, trust assessments, and release passports can
survive real software complexity. Relevant evidence includes contract locks,
release passports, KFD gates, surface-impact classification, package
publishing, web-surface deployments, and future paper/publication artifact
workflows.

Buildchain matters because it converts foundation principles into release
gates. If a product cannot produce facts, bind them into trust evidence, and
surface residual risk, it should not ask users or agents to treat its release
claims as fully trusted.

\subsection{Kungfu}

Kungfu is the product evidence path. It aims to manage real-world work with
agents through local facts, GUI/TUI/CLI/API surfaces, runtime tracing,
extension trust gates, profiles, managed runs, remote imports, and long-cycle
task state.

Kungfu can test the model under pressure. It can show whether local fact
ledgers reduce recovery cost, whether dual-first interfaces help agents use the
product without workflow capture, whether release passports improve trust, and
whether transparent constraints produce better cooperation than hidden control.

\subsection{Evidence status}

The current paper should be read as an initial model and design agenda. Strong
empirical claims require future evidence from the three paths above. The most
important next step is not to add more philosophy, but to turn each layer into
checks, artifacts, and case studies that independent humans or agents can
inspect.
